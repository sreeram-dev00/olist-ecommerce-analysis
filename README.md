# Olist Brazilian E-Commerce Analysis

## Overview
Analysis of 99,441 orders across 9 relational datasets (45 MB) from 
Olist — Brazil's largest e-commerce platform. Built as part of a 
6-month Data Analyst internship at AI Variant.

## Tools Used
- MySQL — multi-table JOINs, DATEDIFF, aggregations, KPI computation
- Microsoft Excel — interactive dashboard with slicers (Year, State, Payment Type)
- Power BI — KPI dashboards, time-series analysis
- Tableau — data visualization and business insights

## Key Insights (5 KPIs)
| KPI | Result |
|-----|--------|
| Weekday vs Weekend Orders | Weekday: 80K orders (77% revenue) vs Weekend: 24K |
| Score 5 + Credit Card Orders | 43,981 orders — highest value segment |
| Pet Shop Avg Delivery | 10.9 days (13% faster than platform average) |
| São Paulo Avg Price/Payment | Price: R$107.53 / Payment: R$135.83 |
| Shipping vs Review Score | 5★ = 10.2 days · 1★ = 20.8 days delivery |

## Total Sales: R$20.6M across 99,441 orders
